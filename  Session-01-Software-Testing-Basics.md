# Software

Software is a collection of computer programs that helps users perform specific tasks. It includes the programs, data, and instructions needed to operate a computer or complete a particular job.

# Types of Software

## 1. System Software

System software manages computer hardware and provides a platform for running application software.

**Examples:** Device drivers, operating systems, servers, and utilities.

## 2. Programming Software

Programming software helps developers create, test, and maintain other software.

**Examples:** Compilers, debuggers, interpreters, and code editors.

## 3. Application Software

Application software is designed to help users perform specific tasks or activities.

**Examples:** Web applications, mobile apps, desktop applications, word processors, and media players.

# Why do we need Testing?

Software testing is an essential activity performed to ensure that a software application works correctly and meets user requirements.

## Objectives of Testing

To identify defects before software is released.
To verify that requirements are implemented correctly.
To improve software quality and reliability.
To reduce maintenance costs after deployment.
To increase customer satisfaction.
To ensure the application performs as expected under different conditions.
To prevent business losses caused by software failures.

**Example**

Imagine an online banking application where users cannot transfer money due to a defect. Proper testing helps identify such issues before the application reaches customers.


# Error,Bug & failure

These terms are related but represent different stages of a defect.

## Error

An error is a human mistake made during requirement analysis, design, coding, or other software development activities.

**Example**

A developer writes incorrect logic for calculating discounts.

## Bug (Defect)

A bug is a flaw in the software caused by an error and discovered during testing.

**Example**

A shopping website applies a 20% discount instead of the required 10%.

## Failure

A failure occurs when a defect reaches production and causes incorrect behavior for end users.

**Example**

Customers are charged the wrong amount due to the discount calculation bug.

# Relationship

Error → Bug (Defect) → Failure




# Why the software has bugs?

Software defects can occur for many reasons during development.

**1. Miscommunication**

Requirements may be misunderstood between clients, analysts, developers, and testers.

**2. Software Complexity**

Modern applications contain thousands or millions of lines of code, increasing the chances of defects.

**3. Programming Mistakes**

Developers may introduce logic errors, syntax errors, or incorrect implementations.

**4. Changing Requirements**

Frequent requirement changes can introduce new defects or break existing functionality.

**5. Time Pressure**

Tight deadlines may reduce development and testing efforts.

**6. Lack of Testing**

Insufficient test coverage can allow defects to remain undetected.

**7. Integration Issues**

Different modules may work correctly individually but fail when integrated.

**8. Human Factors**

Developers, testers, and stakeholders can make mistakes because software development is a human-driven process.
