# Static Testing vs Dynamic Testing

## Static Testing

Static Testing is performed without executing the code.

The purpose is to find defects in requirements, design documents, and source code before execution.

## Examples

Requirement Review

Design Review

Code Review

Walkthrough

Inspection

## Advantages

Defects are found early.

Reduces development cost.

Improves software quality.

**Example**

Reviewing a Software Requirement Specification (SRS) document and identifying missing requirements.

# Dynamic Testing

Dynamic Testing is performed by executing the application or code.

The purpose is to verify that the software behaves as expected.

## Examples

Functional Testing

Integration Testing

System Testing

Regression Testing

User Acceptance Testing (UAT)

## Advantages

Verifies actual application behavior.

Finds runtime defects.

Ensures requirements are implemented correctly.

**Example**

Testing a login page by entering valid and invalid credentials.
